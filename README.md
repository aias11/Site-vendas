🛍️ Sistema Web para Loja
Aplicação web em desenvolvimento para uma loja, com React na interface e C# no back-end para implementar as regras de negócio e a integração com o banco de dados.
🎯 Objetivo
Criar uma plataforma moderna, responsiva e intuitiva para apresentar produtos e facilitar a navegação dos clientes, com uma API responsável pelo processamento e armazenamento dos dados.
🛠️ Tecnologias
- Front-end: React, JavaScript, HTML e CSS
- Back-end: C# (framework a definir)
- Banco de dados: a definir
- Comunicação: API REST (planejada)
✨ Funcionalidades planejadas
- [ ] Página inicial responsiva
- [ ] Catálogo de produtos
- [ ] Página de detalhes dos produtos
- [ ] Busca e filtros de produtos
- [ ] Integração do React com a API em C#
- [ ] Persistência de dados no banco de dados
- [ ] Área administrativa para gerenciamento de produtos
